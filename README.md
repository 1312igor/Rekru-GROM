# 🛡️ Rekrutacja do Agencji GROM
Prosta aplikacja desktopowa w Java Swing symulująca proces rekrutacji do tajnej agencji.

## Funkcje
- Wykorzystanie różnych okien dialogowych `JOptionPane`.
- Obsługa zdarzeń przycisków i okna głównego.
- Personalizacja interfejsu (własna ikona tarczy, wyśrodkowany układ).

## Jak uruchomić?
1. Sklonuj repozytorium.
2. Upewnij się, że masz plik `tarcza.png` w głównym katalogu.
3. Skompiluj i uruchom klasę `Main`.
